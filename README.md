# 디딤을 위한 UDL 3.0 지도안 설계기

디딤과 함께하는 즐거운 운동장 — 2022 개정 교육과정 성취기준을 바탕으로 UDL 3.0 공통 지도안을 설계합니다.

- 제작자: 홍성진 (경상남도교육청)
- 배포 파일: `public/index.html` (한 파일로 동작, 설치·빌드 없음)

## Cloudflare Pages 설정

| 항목 | 값 |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | 비워 둠 |
| Build output directory | `public` |

`main`에 올리면 Cloudflare가 자동으로 다시 배포합니다.

## 참고

- 성취기준은 2022 개정 교육과정 원문(교육부 고시 제2022-34호 [별책 2]·[별책 3], 제2022-33호)을 넣어 두었습니다.
- 입력한 내용은 쓰는 사람의 브라우저에만 저장됩니다.
- Claude 제안 버튼은 claude.ai 아티팩트에서만 보입니다. 이 사이트에서는 「키워드로 빠르게 채우기」와 성취기준 목록 고르기를 씁니다.
